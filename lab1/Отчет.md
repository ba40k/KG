# Лабораторная работа 1

## Вариант
Нечётный вариант.

## Задача
Разработать графическое приложение для просмотра и редактирования цвета в моделях CMYK, RGB и HLS. Программа должна предоставлять следующие возможности:

1. Отображать компоненты цвета отдельно для каждой из трёх моделей.
2. Позволять задавать компоненты вручную в полях ввода и с помощью ползунков.
3. Открывать стандартное диалоговое окно для выбора цвета из палитры.
4. При изменении цвета в любой модели переводить результат в RGB и по нему обновлять значения двух остальных моделей.
5. Показывать цвет в виде образца и выводить его HEX-представление.
6. Проверять введённые значения, не допускать расчётов для некорректных данных и сообщать пользователю об ошибке.

Для компонентов используются диапазоны C, M, Y, K — от 0 до 100; R, G, B — целые значения от 0 до 255; H — от 0 до 360; L и S — от 0 до 100.

## Реализованное приложение
Приложение реализовано в файле [main.py](./main.py) с использованием Tkinter. Главное окно содержит три панели — CMYK, RGB и HLS. В каждой панели для каждого компонента предусмотрены поле ввода, ползунок и кнопка выбора цвета из палитры.

Внутренним представлением выбранного цвета служит тройка RGB. После ввода значения, перемещения ползунка или выбора цвета программа переводит исходные компоненты в RGB, вычисляет значения других моделей и синхронно обновляет поля, ползунки, образец и HEX-код. Значения модели, из которой поступило изменение, сохраняются в исходном виде, чтобы не показывать их повторно округлёнными результатами обратного преобразования.

## Функциональные возможности
- Работа с моделями CMYK, RGB и HLS.
- Изменение компонентов с клавиатуры и ползунками.
- Выбор цвета в стандартном диалоговом окне.
- Автоматическая синхронизация моделей после изменения цвета.
- Отображение визуального образца и HEX-кода.
- Вывод сообщения о некорректном вводе в строке состояния.

## Используемые преобразования
Вычисления выполняются функциями программы, без сторонних библиотек для преобразования цветовых моделей. В преобразованиях используются нормализованные компоненты: значения RGB делятся на 255, а проценты CMYK и HLS — на 100.

### CMYK → RGB
Сначала проценты C, M, Y и K переводятся в диапазон от 0 до 1. Затем рассчитываются каналы:

```text
R = 255 × (1 − C) × (1 − K)
G = 255 × (1 − M) × (1 − K)
B = 255 × (1 − Y) × (1 − K)
```

Полученные каналы округляются до целых чисел, так как RGB в приложении задаётся целыми значениями.

### RGB → CMYK
Каналы RGB нормализуются, после чего находится доля чёрного:

```text
K = 1 − max(R, G, B)
```

Если цвет чёрный (`K = 1`), компоненты C, M и Y полагаются равными нулю, а K — 100%. Эта отдельная проверка предотвращает деление на ноль в следующих формулах. Для остальных цветов рассчитываются:

```text
C = (1 − R − K) / (1 − K)
M = (1 − G − K) / (1 − K)
Y = (1 − B − K) / (1 − K)
```

Результаты переводятся в проценты и округляются до двух знаков после запятой.

### HLS → RGB
H переводится в сектор цветового круга по 60 градусов, а L и S — из процентов в диапазон от 0 до 1. Вычисляются промежуточные величины:

```text
C = (1 − |2L − 1|) × S
X = C × (1 − |(H / 60 mod 2) − 1|)
m = L − C / 2
```

Оттенок делит цветовой круг на шесть секторов. В зависимости от сектора величины C и X распределяются по каналам R, G и B; к каждому каналу добавляется m. Результат умножается на 255 и округляется до целого. Перед вычислением H нормализуется по модулю 360, поэтому значение на границе круга обрабатывается как начальный оттенок.

### RGB → HLS
После нормализации RGB определяются максимальный и минимальный каналы, их разность и светлота:

```text
max = max(R, G, B)
min = min(R, G, B)
Δ = max − min
L = (max + min) / 2
```

Если `Δ = 0`, цвет ахроматический: оттенок и насыщенность устанавливаются в 0. Иначе насыщенность вычисляется по формуле `Δ / (max + min)` при `L ≤ 0,5` или `Δ / (2 − max − min)` при `L > 0,5`. Оттенок определяется по тому, какой канал RGB является максимальным; результат переводится в градусы. H, L и S округляются до двух знаков, а H приводится к диапазону цветового круга.

Поскольку RGB содержит целые каналы, а CMYK и HLS — дробные величины, обратное преобразование может дать небольшую погрешность округления. Поэтому значения модели-источника сохраняются при обновлении интерфейса; пересчитанные значения в других моделях показывают представление того же цвета с точностью, доступной соответствующей модели.

## Обработка ошибок и проверка данных
Перед преобразованием введённые поля обрабатываются следующим образом:

1. Удаляются пробелы в начале и конце строки.
2. Значение преобразуется в число. Если строка пустая или содержит нечисловые данные, вычисление прекращается и выводится сообщение с названием компонента.
3. Проверяется, что значение конечно: `NaN` и бесконечность не допускаются.
4. Для RGB дополнительно проверяется, что значение целое.
5. Проверяется попадание значения в допустимый диапазон соответствующей модели.
6. Только после успешной проверки запускается преобразование и обновление остальных элементов.

При ошибке программа выводит сообщение в строке состояния и не выполняет пересчёт по недопустимым значениям. Перемещение ползунка формирует значение в заданном диапазоне с целым шагом, которое также проходит общую проверку. Если диалог выбора цвета закрыть без выбора, текущее состояние приложения не меняется.

При обновлении полей и ползунков устанавливается флаг `updating`. Он не позволяет обработчикам ползунков повторно запускать преобразования в ответ на программное обновление интерфейса. После синхронизации флаг снимается, и пользовательский ввод снова обрабатывается обычным образом.

## Как запустить
1. Откройте папку проекта.
2. Запустите приложение командой:

```bash
python main.py
```

## Проверка
При проверке приложения следует убедиться в следующем:

- преобразования CMYK → RGB, RGB → CMYK, HLS → RGB и RGB → HLS дают ожидаемые значения для основных цветов, белого и чёрного;
- для ахроматических цветов RGB → HLS возвращает нулевые оттенок и насыщенность;
- обратный пересчёт RGB сохраняет значения каналов с погрешностью не более одной единицы из-за округления;
- корректные граничные значения принимаются, а значения за пределами диапазона, дробные значения RGB, пустой ввод и нечисловые данные вызывают сообщение об ошибке;
- выбор цвета обновляет три модели, образец и HEX-код, а отмена выбора оставляет текущий цвет без изменений;
- ввод и перемещение ползунков синхронизируют все модели без повторного вызова обработчиков при обновлении интерфейса.
