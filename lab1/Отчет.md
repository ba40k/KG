# Лабораторная работа 1

## Тема
Изучение цветовых моделей: CMYK, RGB, HLS

## Вариант
Нечётный вариант.

## Задача
В приложении необходимо реализовать возможность:
- задавать цвет в любой из моделей: CMYK, RGB, HLS;
- изменять значения вручную;
- управлять параметрами через ползунки;
- выбирать цвет из палитры;
- автоматически пересчитывать значения в остальных моделях при изменении любого параметра.

Также требовалось обеспечить:
- корректное отображение результата;
- простую и понятную структуру программы;
- оформление в стиле старых программ (Y2K).

## Реализованное приложение
Было создано приложение [main.py](./main.py), которое отображает три панели:
- CMYK
- RGB
- HLS

Каждая панель содержит:
- поля ввода числовых значений;
- ползунки для изменения параметров;
- кнопку выбора цвета из палитры.

При изменении параметра в одной модели автоматически пересчитываются все остальные модели, а также обновляется визуальный образец цвета и HEX-код.

## Функциональные возможности
- Работа в трёх цветовых моделях: CMYK, RGB, HLS
- Автоматическое согласование значений между моделями
- Ползунки и ручной ввод значений
- Выбор цвета через стандартное диалоговое окно
- Совместимость с форматом старого интерфейсного стиля Y2K

## Используемые преобразования
Формулы преобразования цветовых моделей реализованы непосредственно в программе, без библиотек для работы с цветовыми пространствами:
- CMYK → RGB и RGB → CMYK;
- HLS → RGB и RGB → HLS.

Для HLS → RGB цвет переводится в шестисекторную модель оттенка, после чего вычисляются компоненты RGB. Для RGB → HLS вычисляются максимальная и минимальная нормализованные компоненты, яркость, насыщенность и оттенок. Для преобразования CMYK используются формулы пересчёта с компонентой чёрного.

Для интерфейса используется Tkinter из стандартной библиотеки Python; преобразование цветов от Tkinter не зависит.

## Как запустить
1. Откройте папку проекта.
2. Запустите приложение командой:

```bash
python main.py
```

## Проверка
Проверены:
- корректность преобразования из CMYK в RGB;
- корректность RGB → CMYK и RGB ↔ HLS;
- проверка обратного пересчёта цветовых значений;
- точность обратного пересчёта RGB с погрешностью не более одной единицы канала;
- корректная работа ввода значений и интерфейса Tkinter.

В результате была разработана простая программа, соответствующая требованиям лабораторной работы, с функционалом преобразования и визуального редактирования цвета в трёх моделях. Приложение отличается минималистичной структурой, лёгкостью сопровождения и ретро-дизайном в стиле Y2K.
