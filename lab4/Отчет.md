# Лабораторная работа 4

## Тема
Разработка приложения для формирования и визуализации трехмерного объекта на основе фамилии в кириллическом написании. В качестве трехмерного объекта используется объемная модель фамилии, построенная по массиву вершин и граней. Реализованы базовые трехмерные преобразования с отображением итоговой матрицы.

## Цель
Разработать графическое приложение, которое:
- формирует 3D-объект фамилии "ТКАЧЕНКО";
- строит модель по массиву вершин и поверхностям (граням);
- отображает объемную фигуру с текстурным/цветовым заполнением;
- поддерживает масштабирование, поворот и сдвиг объекта;
- выводит текущую матрицу преобразования.

## Задание
Согласно условию лабораторной работы необходимо:
- написать приложение или веб-приложение;
- сформировать и визуализировать трехмерный объект;
- в качестве объекта взять трехмерное изображение фамилии;
- задавать объект с помощью массива координат вершин;
- выполнять трехмерные преобразования;
- выводить итоговую матрицу преобразования.

## Реализация
Приложение реализовано на Python с использованием стандартного пакета Tkinter.

### Основные элементы программы
- `build_cube(...)` — создает куб по центру и размеру;
- `build_textured_surname_mesh(...)` — строит 3D-модель фамилии по пиксельному/воксельному шаблону;
- `rotation_x`, `rotation_y`, `rotation_z` — матрицы поворота;
- `scaling` — матрица масштабирования;
- `translation` — матрица переноса;
- `multiply_matrices` — перемножение матриц преобразования;
- `transform_vertices` — применение матрицы к вершинам;
- `project_vertex` — проекция 3D в 2D;
- `TexturedSurnameApp` — графический интерфейс программы.

### Схема построения модели
Для каждой буквы фамилии задается пиксельный шаблон в виде 5x7 матрицы. Каждая активная ячейка преобразуется в миниатюрный куб. Все кубы соединяются в единую сетку, получая тем самым объемную форму фамилии.

Матрица объекта задается через набор вершин и граней:
- вершина — кортеж `(x, y, z)`;
- грань — набор индексов вершин и цвет.

В итоге получается полигональная 3D-модель фамилии, которая после проекции на плоскость экрана отображается пользователю.

## Трехмерные преобразования
В программе поддерживаются:
- поворот вокруг оси X;
- поворот вокруг оси Y;
- поворот вокруг оси Z;
- масштабирование;
- перемещение по осям.

Каждое преобразование задается матрицей 4x4, а совокупный результат формируется по формуле:

M_total = M_new × M_old

где:
- `M_old` — уже примененная матрица;
- `M_new` — новая матрица преобразования.

Все точки объекта умножаются на итоговую матрицу, после чего выполняется проекция в 2D для отображения на экране.

### Однородные координаты
Для работы с матрицами 4x4 трехмерная точка `(x, y, z)` представляется в однородных координатах как `(x, y, z, 1)`. Дополнительная координата позволяет задавать перенос в виде матричного преобразования: смещения по осям X, Y и Z помещаются в четвертый столбец матрицы.

Использование однородных координат дает следующие преимущества:
- поворот, масштабирование и перенос можно представлять матрицами одного размера;
- последовательность преобразований можно объединить перемножением матриц, а затем применить к вершине одним вычислением;
- порядок преобразований явно задается порядком перемножения матриц;
- единый формат упрощает реализацию и применение преобразований ко всем вершинам модели.

После преобразования первые три координаты используются как новые координаты вершины `(x', y', z')`. Однородные координаты не означают, что модель становится четырехмерной: четвертая координата служит математическим способом объединить трехмерные преобразования, включая перенос.

## Вывод матрицы
В интерфейсе программы отображается текущее преобразование в виде матрицы 4x4. Пользователь может нажимать кнопки:
- "Повернуть X";
- "Повернуть Y";
- "Повернуть Z";
- "Масштаб +10%";
- "Сдвиг";
- "Сброс".

После каждого действия матрица обновляется и выводится в окне.

## Визуализация
Фамилия отображается в 3D как объемный объект с выделением граней и подсветкой. Для каждого лица используется цветовая палитра, а также простое текстурное/узорное дополнение, что позволяет получить более выразительный вид модели.
