# Лабораторная работа «Алгоритмы отсечения отрезков и многоугольников»

**Вариант 11. Язык реализации: Python.**

## Цель работы

Изучить алгоритмы отсечения отрезков и выпуклых многоугольников прямоугольным окном. Реализовать алгоритм Лианга–Барски и алгоритм Сазерленда–Ходжмана, визуализировать их работу и проверить результаты на контрольных примерах.

## Постановка задачи

Требуется разработать графическое приложение, которое отображает систему координат с одинаковым масштабом по осям, прямоугольное окно и исходные фигуры. Программа должна находить и выделять видимую часть объектов: в первой части работы это отрезки, во второй — выпуклый многоугольник.

## Теоретические сведения

### Алгоритм Лианга–Барски

Пусть концы отрезка заданы точками \(A=(x_1,y_1)\) и \(B=(x_2,y_2)\). Обозначим \(\Delta x=x_2-x_1\), \(\Delta y=y_2-y_1\). Тогда произвольная точка отрезка имеет вид

\[
P(t)=\bigl(x_1+t\Delta x,\ y_1+t\Delta y\bigr),\qquad 0\le t\le 1.
\]

Точка лежит внутри окна или на его границе, если \(x_{\min}\le x(t)\le x_{\max}\) и \(y_{\min}\le y(t)\le y_{\max}\). Подставляя параметрические координаты, получаем четыре неравенства вида \(p_k t\le q_k\) ([лекция Университета Ноттингема об отсечении](https://people.cs.nott.ac.uk/pszqiu/Teaching/Courses/G5BAGR/Slides/7-clipping.pdf)):

| Граница | \(p_k\) | \(q_k\) |
|---|---:|---:|
| Левая | \(-\Delta x\) | \(x_1-x_{\min}\) |
| Правая | \(\Delta x\) | \(x_{\max}-x_1\) |
| Нижняя | \(-\Delta y\) | \(y_1-y_{\min}\) |
| Верхняя | \(\Delta y\) | \(y_{\max}-y_1\) |

Изначально допустим весь интервал \([0,1]\). При \(p_k<0\) знак неравенства при делении меняется: \(t\ge q_k/p_k\), поэтому уточняется нижняя граница интервала. При \(p_k>0\) получаем \(t\le q_k/p_k\), поэтому уточняется верхняя граница. При \(p_k=0\) делить не нужно: если \(q_k<0\), отрезок целиком вне разрешённой полуплоскости; иначе эта граница ничего не ограничивает. Так алгоритм находит самый поздний допустимый вход и самый ранний допустимый выход ([лекция Carnegie Mellon по компьютерной графике](https://www.cs.cmu.edu/~fp/courses/graphics/pdf-2up/13-clip.pdf)).

\[
t_{\mathrm{вх}}=\max\bigl(\{0\}\cup\{q_k/p_k:p_k<0\}\bigr),\qquad
t_{\mathrm{вых}}=\min\bigl(\{1\}\cup\{q_k/p_k:p_k>0\}\bigr).
\]

При \(t_{\mathrm{вх}}>t_{\mathrm{вых}}\) видимой части нет. Иначе её концы определяются подстановкой этих значений в \(P(t)\). Если параметры равны, результатом является одна точка.

### Алгоритм Сазерленда–Ходжмана

Многоугольник задаётся вершинами в порядке обхода. Алгоритм последовательно отсекает его по левой, правой, нижней и верхней границам окна. После каждого прохода получается новый список вершин, который используется на следующем проходе. В пределах одного прохода проверяется принадлежность только текущей полуплоскости; точка на её границе считается внутренней ([лекция Университета Техаса об отсечении многоугольников](https://www.cs.utexas.edu/~bajaj/graphics23/cs354/lect04.pdf)).

При обработке ребра \(S\to E\) возможны четыре случая. Через \(I\) обозначена точка пересечения ребра с текущей границей ([правила обхода Сазерленда–Ходжмана](https://www2.cs.sfu.ca/CourseCentral/361/hyounesy/Lectures/10-clipping.pdf)).

| Положение \(S\) | Положение \(E\) | Что добавить в новый список |
|---|---|---|
| Внутри | Внутри | \(E\) |
| Внутри | Снаружи | \(I\) |
| Снаружи | Внутри | \(I\), затем \(E\) |
| Снаружи | Снаружи | Ничего |

Для вертикальной границы \(x=c\) параметр пересечения равен \(t=(c-x_S)/(x_E-x_S)\), а сама точка имеет координаты \(\bigl(c,\ y_S+t(y_E-y_S)\bigr)\). Для горизонтальной границы формула аналогична с перестановкой координат. При обходе учитывается и ребро, соединяющее последнюю вершину с первой ([лекция Университета Техаса об отсечении многоугольников](https://www.cs.utexas.edu/~bajaj/graphics23/cs354/lect04.pdf)).

Если при обходе контур выходит из разрешённой полуплоскости и затем возвращается, внешние вершины удаляются. Точки выхода и входа становятся соседними в новом списке и образуют ребро вдоль границы окна. Поэтому отсечение многоугольника нельзя заменить независимым отсечением его исходных рёбер ([лекция WPI по компьютерной графике](https://web.cs.wpi.edu/~emmanuel/courses/cs543/f11/slides/lecture09_p2.pdf)).

## Реализация программы

Модуль `clipping.py` содержит функции отсечения и чтения исходных данных. Файл `app.py` запускает окно Tkinter со встроенным графиком Matplotlib. Приложению не требуются аргументы командной строки: демонстрации и загрузка файлов доступны через кнопки. На графике окно показано синим, исходные фигуры — серым пунктиром, видимые части — зелёным.

Для установки зависимости и запуска из папки проекта используются команды:

```bash
python -m pip install -r requirements.txt
python app.py
```

Файл `segments.txt` начинается с количества отрезков. Далее идут строки с координатами `x1 y1 x2 y2` для каждого отрезка. В файле `polygon.txt` первая строка задаёт количество вершин, далее идут координаты `x y` в порядке обхода. В обоих форматах последняя строка задаёт окно: `xmin ymin xmax ymax`.

## Результаты

### Отсечение отрезков

Для окна \([0,10]\times[0,8]\) программа находит видимые части у семи из восьми отрезков: два находятся внутри окна целиком, пять отсекаются частично, один лежит целиком левее окна.

Для контрольного отрезка от \((-2,1)\) до \((12,9)\) имеем \(x(t)=-2+14t\), \(y(t)=1+8t\). Ограничения по \(x\) дают \([1/7,6/7]\), а ограничения по \(y\) — \([-1/8,7/8]\). Их пересечение с \([0,1]\) равно \([1/7,6/7]\). Подстановка даёт видимый отрезок от \((0,15/7)\) до \((10,55/7)\).

Все семь тестов пройдены.

## Вывод

Контрольный пример показывает, что не все границы окна определяют концы видимой части отрезка: в данном случае нижняя и верхняя границы не сужают интервал, уже заданный левой и правой границами. Поэтому в алгоритме Лианга–Барски важно не просто найти пересечения с прямыми, ограничивающими окно, а выбрать те ограничения, которые действительно задают начало и конец видимой части.

При отсечении многоугольника важно сохранить замкнутый контур. На примере ромба видно, что удаление внешней части может даже увеличить число вершин: срезанные углы заменяются новыми рёбрами вдоль сторон окна. Если отсекать исходные рёбра по отдельности, эти новые рёбра не появятся и контур останется разомкнутым. Именно поэтому для отрезка достаточно определить два конца, а для многоугольника нужно заново собрать границу видимой области.
